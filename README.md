# 📚 Learning Philosophy

I don't want to just learn frameworks.

I want to understand the layers underneath them.

```text
Framework
    ↓
Runtime
    ↓
Protocol
    ↓
Architecture
    ↓
Computer Science
```

For example:

```text
Next.js
   ↓
React
   ↓
JavaScript Runtime
   ↓
HTTP / Browser / Server
   ↓
Networking + OS + CS Fundamentals
```

That mindset is something I want to carry into every technology I learn.
